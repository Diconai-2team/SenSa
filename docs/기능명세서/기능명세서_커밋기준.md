### 27-1. 탐지 방식 2종

| 방식 | 탐지 축 | 원리 | 알람 메시지 접두사 |
|------|--------|------|-----------------|
| Isolation Forest (IF) | 공간축 — 여러 센서 조합 | 여러 측정값 패턴이 평소와 다를 때 이상 판정 | `[이상탐지]` |
| ARIMA | 시간축 — 단일 센서 추세 | 과거 시계열로 미래 예측, 임계치 진입 예상 시 경보 | `[ARIMA]` |

### 27-2. IF 탐지 발동 조건

- 센서 데이터 수신 누적 **30개 이상**부터 작동
- 이상 점수가 기준 미만(CONTAMINATION 5%)이면 알람 생성
- 20번 수신마다 모델 자동 재학습

---

### 27-3. AI 알람 생성 → 화면 표시 전체 흐름

```
POST /devices/sensor-data/
  ├─ 기존 임계치 판정 (classify_gas/classify_power)
  └─ detect_anomaly() — IF 이상 판정
       ├─ 정상 → 종료
       └─ 이상 감지 → Alarm DB 저장 (alarm_type='ai_anomaly')
                        └─ publish_alarm() → Redis → WebSocket
                             └─ SenSa.on('alarm') → resolveTab() → AI탭
```

### 27-4. AI탭 알람 아이템 표시 형식

|------|------|

| 메시지 | `[이상탐지] {device_id} — 패턴 이상 감지 (score: -0.xxx)` |
| AI 배지 | 메시지 옆 파란 `AI` 배지 |

|---------|-----------|
